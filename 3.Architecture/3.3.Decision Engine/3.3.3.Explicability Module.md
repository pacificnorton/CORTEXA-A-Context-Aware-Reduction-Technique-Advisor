## Explicability Module

CORTEXA does not only recommend data-reduction methods; it also explains why these methods are recommended.

The explicability module is designed to help users understand both the recommendation process and the trade-offs behind each suggested method. It consists of two complementary components:

### Visual Explanation

Each recommendation is associated with a radar chart displaying its normalized scores across the four objectives considered by CORTEXA:

- Performance Preservation
- Reduction Volume
- Interpretability
- Computational Cost

The radar chart provides a quick overview of the strengths and weaknesses of a method and allows users to compare recommendations visually.

### Textual Explanation

Additional details can be accessed through the information icon (**ⓘ**) displayed next to each recommendation.

The generated explanation describes:

1. Why the method is compatible with the dataset characteristics and analytical task.
2. Why it belongs to the Pareto-optimal set.
3. Which objectives it satisfies particularly well.
4. How the user-defined priority order influenced its final ranking.

For example:

- **Mutual Information (MI)** may be recommended when performance is the highest-priority objective because it retains the most informative features for the prediction task while remaining interpretable.

- **Cluster Sampling** may be recommended when reduction efficiency is prioritized because it reduces the number of processed instances while maintaining acceptable performance and preserving the original feature space.

Together, the visual and textual explanations transform a simple recommendation list into a transparent decision-support process, allowing users to understand the trade-offs behind each recommendation rather than treating the system as a black box.
