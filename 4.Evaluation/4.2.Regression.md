# Regression Experiments

## Objective

The regression experiments were designed to evaluate three key properties of CORTEXA:

1. **Coherence with practitioner choices**  
   Verify whether the system recommends reduction methods commonly used in real-world implementations when the optimization priorities reflect the objectives typically pursued by practitioners.

2. **Ability to identify superior alternatives**  
   Assess whether CORTEXA can recommend reduction strategies that outperform the methods selected by practitioners when empirical evidence indicates that alternative trade-offs are more advantageous.

3. **Sensitivity to objective priorities**  
   Verify that recommendations change consistently when users modify the importance assigned to the optimization objectives, demonstrating that preference-based decision making is performed during the online phase.

---

## Experimental Setup

Three regression datasets were selected from publicly available Kaggle implementations that already contained:

- A regression task;
- A baseline predictive model;
- An expert-selected data reduction technique.

This setup allowed direct comparison between:

- The reduction strategy chosen by practitioners;
- The recommendations generated by CORTEXA.

### Datasets

| Dataset | Practitioner Reference |
|----------|----------|

The top recommendation generated by CORTEXA was compared against:

- The baseline regression model (without reduction);

---

## Observations

### Gold Price Dataset

The practitioner selected PCA as the reduction strategy.

CORTEXA recommended a hybrid reduction approach combining PCA and Cluster Sampling. This recommendation preserved the dimensionality reduction benefits of PCA while additionally reducing the number of observations processed by the predictive model.

The resulting configuration achieved:

- Higher predictive performance;
- Substantially greater reduction volume;
- Comparable interpretability and computational footprint.

### Car Price Dataset

The practitioner implementation relied on RFE.

CORTEXA instead recommended Cluster Sampling as the most suitable reduction strategy under the observed dataset characteristics and objective priorities.

The recommendation achieved:

- Higher predictive performance;
- Greater reduction effectiveness;
- Lower computational cost.

### House Price Dataset

The practitioner implementation used PCA.

CORTEXA recommended a hybrid reduction strategy combining PCA and Variance Threshold filtering.

Although the performance improvement was modest, the recommended configuration produced a substantial reduction in data volume while maintaining predictive quality.

# Scenario 2: Computational-Cost Priorities

## Priority Ordering

1. Computational Cost
2. Reduction Effectiveness
3. Interpretability
4. Predictive Performance

This scenario evaluates the sensitivity of recommendations to changes in user priorities.

### Recommendations

| Dataset | Rank | Recommended Reduction Method |
|----------|----------|----------|
| Gold Price | 1 | Cluster Sampling |
| | 2 | Random Sampling |
| | 3 | PCA |
| Car Price | 1 | Cluster Sampling |
| | 2 | Stratified Sampling |
| | 3 | RFE |
| House Price | 1 | Cluster Sampling |
| | 2 | Random Sampling |
| | 3 | Mutual Information |

---

## Observations

Changing only the priority ordering produced a different ranking of recommended reduction methods across all datasets.

When computational efficiency became the primary objective:

- Instance-based reduction methods moved to the top of the rankings;
- Sampling strategies became dominant;
- More computationally intensive feature-selection and dimensionality-reduction techniques were deprioritized.

These results confirm that:

1. Preference information is incorporated explicitly during the online recommendation phase;
2. Recommendations are not fixed for a given dataset profile;
3. CORTEXA adapts its recommendations according to user-defined optimization objectives.

---

# Conclusions

The regression experiments demonstrate that CORTEXA:

- Produces recommendations consistent with established practitioner choices when priorities align with common practice;
- Identifies alternative reduction strategies that can outperform expert-selected approaches;
- Successfully combines feature-based and instance-based reduction methods when beneficial;
- Adapts recommendations to changing objective priorities;
- Provides a transparent and context-aware mechanism for regression-oriented reduction-method selection.
